## Goal

Create a **public** minimal developer website (“Dev Site”) with **Next.js (App Router)** and **React (latest)** that consumes my published design-system package.  
Priorities: **SSR first**, **speed**, **tiny bundle**, **no styling bloat**.

- Use **React (latest)** and **Next.js (App Router)**.
- Consume components from **`@noahwright/design-system`** (already published).
- Use a **typed theme pipeline**: `theme.ts` ➜ build script ➜ emits `public/theme.css`.  
- No Storybook in this repo (link out to the Storybook hosted by the design-system repo).

---

## Non-Negotiable Guardrails

- **Do not** add Tailwind, SCSS/LESS, styled-components, emotion, runtime CSS-in-JS, PostCSS, CSS resets, or utility class soup.
- **Do not** invent layout/spacing/animation utilities.
- **Do not** auto-inject CSS from the library entry. Consumers must import their own generated `public/theme.css`.
- **SSR safe by default:** no `window` or side effects outside explicit client components.
- **Keep files and code minimal**. If anything is ambiguous, stop and quote the blocking line from this file.

### `scripts/build-theme.ts`
```ts
import { writeFileSync, mkdirSync, existsSync } from "node:fs";
import { buildThemeCss } from "@noahwright/design-system";
import { theme } from "../theme";

if (!existsSync("public")) mkdirSync("public");
writeFileSync("public/theme.css", buildThemeCss(theme), "utf8");
console.log("Wrote public/theme.css");
```
